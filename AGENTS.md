# Polyrhythmer — instrukcje startowe

Jeśli istnieje `.local/agents/AGENTS.md`, przeczytaj go jako router lokalnej współpracy. Dobieraj dalsze pliki do zadania, bez wczytywania całego workspace'u.

W kopii bez prywatnego `.local/` korzystaj z `docs/README.md`: architektura w `docs/ARCHITECTURE.md`, komendy w `docs/DEVELOPMENT.md`, uruchomienie i scenariusze ręczne w `docs/TRY_IT.md`, fizyczny odbiór w `docs/QA.md`.

Pracuj po polsku, zachowuj istniejące zmiany, weryfikuj rezultat i dostarczaj konkretne instrukcje samodzielnego testowania. Po ukończeniu i zweryfikowaniu każdego taska utwórz osobny commit obejmujący wyłącznie jego zmiany i wypchnij go do skonfigurowanego remote GitHub. Ta stała zgoda na commit i push obowiązuje wyłącznie w tym repozytorium; nie obejmuje publikacji, wdrożenia ani dołączania zmian niezwiązanych z taskiem. Jeśli commit lub push nie może zostać bezpiecznie wykonany, pozostaw zmiany lokalnie i jasno opisz przeszkodę. Test przeglądarkowy nie jest dowodem jakości odsłuchu ani działania na fizycznym telefonie.
